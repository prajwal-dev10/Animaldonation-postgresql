 Animal Welfare Donation & Awareness Platform

A web-based platform dedicated to supporting animal welfare activities such as donations, awareness campaigns, and community engagement for stray and rescued animals.

 🌟 Project Overview

This project aims to connect people who care about animals with rescue initiatives and donation opportunities. It provides a simple and accessible way for users to contribute to animal welfare efforts.

## ✨ Features

* 🐾 Information about animal welfare activities
* 💰 Donation section for supporting rescue efforts
* 📢 Awareness posts/events (e.g., feeding programs, rescue stories)
* 🐶 Animal profiles / stories
* 📱 Simple and responsive UI for easy access

## 🛠️ Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Flask (Python) 
* Database: SQLite , SQLALCHEMY

## 🎯 Purpose

The goal of this project is to raise awareness about stray animals and make it easier for people to contribute to their care and protection.
